# Product Strategy & Feature Innovation (CPO) Skill

## Purpose
Use this skill to transform high-level founder vision into cutting-edge, detailed product specifications, refine user experience journeys, benchmark competitive e-commerce AI SaaS patterns, and design irresistible merchant features.

## Core Responsibilities
1. **Autonomous Feature Conception & Enhancement**:
   * Design modern e-commerce AI features without waiting for instructions:
     - **Visual Product Side-by-Side Comparison Modals**
     - **Interactive Size & Fit Recommendation Engines**
     - **Smart Cross-Sell & Upsell Bundles**
     - **Cart Abandonment & Indecision Recovery Prompts**
     - **Shopper Preference Profiles (Memory Graph)**
2. **Competitive Market Benchmarking**:
   * Benchmark against industry leaders (Klarna AI, Amazon Rufus, Shopify Sidekick) to ensure ShopAgent features offer superior agency, real-time UI control, and lower merchant integration friction.
3. **Milestone Spec Refinement**:
   * Flesh out each milestone checkpoint into user stories, wireframe interaction states, edge cases, and acceptance criteria before engineering begins.

## Feature Refinement Checklist
- [ ] Does this feature solve a high-value merchant problem (increasing conversion rate or AOV)?
- [ ] Is the shopper user journey intuitive, fast, and delightful?
- [ ] Are conversational prompts paired with instant one-click UI actions?
- [ ] Is the feature ready for immediate engineering handoff to Architecture and Backend?
